# SOP-SUPPLY-01 : Gestion d'une rupture de matière première

Lorsqu'une matière passe sous son seuil minimum, le planificateur doit alerter les achats et le fournisseur qualifié.
Pour les principes actifs critiques (ex. enoxaparine), un fournisseur secondaire qualifié peut être sollicité.
Les ordres de fabrication concernés sont replanifiés après confirmation de la date de livraison.
Action recommandée : relever le seuil minimum des principes actifs à délai fournisseur long.
